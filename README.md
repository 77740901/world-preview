# World Preview Unofficial

A Minecraft mod for visualizing world seeds before they are generated. This is an **unofficial port** of [World Preview](https://github.com/caeruleusDraconis/world-preview) to Minecraft 26.2 (Fabric).

## More translations

This fork adds an optional **More translations** feature. It can be toggled in the settings screen (General tab) and adds translations for several languages.
